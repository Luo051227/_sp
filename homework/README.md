## 📚 什麼是「系統程式」？

在開始介紹各個習題之前，先讓我們用一句話了解什麼是系統程式：

> **系統程式 = 幫電腦「管好自己」的軟體**

你平常用的 App（IG、YouTube、計算機…）是「應用程式」，它們是給**人**用的；而系統程式是給**其他程式**用的幕後功臣，例如作業系統、編譯器、驅動程式等等。

這學期我們從零開始，動手做了一個小型的編譯器、自己發明一個程式語言、寫了密碼產生器、研究多執行緒、行程與檔案，最後還探討了記憶體安全。下面就讓我們一個一個來看吧！

## 🛠️ 習題 1 — p0 編譯器（函數呼叫機制）

🔗 [習題 1 完整內容](https://github.com/Luo051227/_sp/tree/master/homework/習題%201%20)

### 🎯 這個習題在做什麼？

我們自己寫了一個超迷你的編譯器，命名為 **p0**。它可以讀懂類似 C 語言的小程式，並且把它「翻譯」成電腦能跑的指令。

更酷的是，這個編譯器**支援函數呼叫**與 `while` 迴圈，這是真正編譯器（例如 GCC、Clang）的核心功能。

### 💡 你會學到什麼？

| 概念 | 白話解釋 |
|:---|:---|
| **詞法分析 (Lexer)** | 把一整段程式碼「切」成一個個有意義的小單位（Token） |
| **語法分析 (Parser)** | 檢查這些小單位的順序是否合法，並產生「四元組」中間碼 |
| **虛擬機 (VM)** | 一個模擬的 CPU，用來執行我們產生的中間碼 |
| **堆疊幀 (Stack Frame)** | 函數呼叫時，幫我們記住「現在執行到哪裡、要回到哪裡」 |

### 🍽️ 生活中的比喻

習題 1 用「**餐廳包廂**」來比喻堆疊幀：

- 全域環境 = 餐廳大廳
- 函數環境 = 進入一個包廂
- 離開函數 = 走出包廂，回到大廳

每個包廂都是獨立的空間，裡面的「客人」（變數）不會互相干擾，這就是為什麼函數內的變數不會影響外面的世界。

### 📂 檔案說明

| 檔案 | 說明 |
|:---|:---|
| `1.py` | p0 編譯器主程式（含 Lexer、Parser、VM） |
| `README.md` | 超詳細教學文件，含流程圖、完整範例、動手練習 |

### ✨ 程式執行範例

```bash
python 1.py test.txt
# 輸入：func fib(n) { if (n < 2) return n; return fib(n-1) + fib(n-2); }
# 輸出：result = 5
```

## 🛠️ 習題 2 — SimpleScript（自製程式語言）

🔗 [習題 2 完整內容](https://github.com/Luo051227/_sp/tree/master/homework/習題%202)

### 🎯 這個習題在做什麼？

習題 1 是「編譯器」，習題 2 我們更進一步，**自己發明一個程式語言**，叫做 **SimpleScript**！

這個語言支援變數、運算、`if` 判斷、`for`/`while` 迴圈、函數、陣列、甚至**模組匯入**。我們用 Python 實作了完整的直譯器來執行它。

### 💡 你會學到什麼？

| 元件 | 角色 | 白話解釋 |
|:---|:---|:---|
| **lexer.py** | 詞彙分析 | 把程式碼切成 Token |
| **parser.py** | 語法分析 | 把 Token 變成「抽象語法樹 (AST)」 |
| **interpreter.py** | 直譯器 | 走訪 AST，一步步執行程式 |
| **simplescript.py** | 主程式 | 把上面三個串起來 |

### 📖 SimpleScript 語法範例

```simplescript
fn fib(n: int) -> int {
    if n <= 1 {
        return n;
    }
    return fib(n - 1) + fib(n - 2);
}

for i = 0, 10, 1 {
    print("fib(" + str(i) + ") = " + str(fib(i)));
}
```

### 🤔 直譯器 vs 編譯器

- **編譯器**：把整本書一次翻譯完才能看（C、C++、Go）
- **直譯器**：像同聲傳譯，邊讀邊翻譯（Python、JavaScript、SimpleScript）

| 檔案 | 說明 |
|:---|:---|
| `lexer.py` | 詞彙分析器 |
| `parser.py` | 語法分析器 |
| `interpreter.py` | 直譯器 |
| `simplescript.py` | 主進入點（執行 `.ss` 檔案） |
| `hello.ss`、`fibonacci.ss`、`main.ss`、`utils.ss` | SimpleScript 範例程式 |

## 🛠️ 習題 5 — 執行緒與同步機制

🔗 [習題 5 完整內容](https://github.com/Luo051227/_sp/tree/master/homework/習題%205)

### 🎯 這個習題在做什麼？

當一個程式裡面**同時有多個任務在跑**（多執行緒），就會出現「**誰先誰後**」的問題。這個習題用 Python 實作了三個經典的同步問題。

### 💡 你會學到什麼？

| 概念 | 白話解釋 |
|:---|:---|
| **執行緒 (Thread)** | 一個程式裡面的「小分身」，可以同時做多件事 |
| **競爭條件事 (Race Condition)** | 兩個分身搶著改同一個變數，結果亂掉 |
| **互斥鎖 (Mutex)** | 一次只准一個分身進去動那個變數，其他人排隊 |
| **死結 (Deadlock)** | 兩個人互相等對方讓路，結果都卡住 |

### 🍽️ 生活中的比喻

想像**餐廳裡的廁所**：
- 互斥鎖 = 廁所的門鎖，鎖上就別人進不去
- 死結 = A 鎖了第一間廁所等第二間，B 鎖了第二間等第一間，**兩人都出不來**

### 📂 三個經典實作

#### 1️⃣ 銀行存款模擬（`銀行存款模擬.py`）

模擬同一個帳戶被多個執行緒同時存提款，**使用 `Lock` 保護餘額**，避免金額出錯。

```bash
python3 銀行存款模擬.py
```

#### 2️⃣ 生產者-消費者問題（`生產者消費者.py`）

模擬工廠生產線：生產者放東西進倉庫，消費者從倉庫拿東西。要處理「**倉庫滿了**」和「**倉庫空了**」的問題。

```bash
python3 生產者消費者.py
```

#### 3️⃣ 哲學家用餐問題（`哲學家用餐.py`）

五位哲學家坐在圓桌前，每個人需要**兩支叉子**才能吃飯。用「**奇偶策略**」避免死結。

```bash
python3 哲學家用餐.py
```

## 🛠️ 習題 6 — 行程與檔案

🔗 [習題 6 完整內容](https://github.com/Luo051227/_sp/tree/master/homework/習題%206)

### 🎯 這個習題在做什麼？

這個習題進入 **Linux/Unix 的核心世界**，學習作業系統怎麼「**生出新程式**」以及「**控制檔案**」。

### 💡 你會學到什麼？

| 系統呼叫 | 功能 | 白話比喻 |
|:---|:---|:---|
| `os.fork()` | 複製一個自己 | 影印機，影印一份完全相同的「你」 |
| `os.execvp()` | 換成新程式 | 把房子裡的機器全部換成新的 |
| `os.open()` / `read()` / `write()` / `close()` | 開檔、讀檔、寫檔、關檔 | 打開抽屜、看東西、放東西、關抽屜 |
| `os.dup2()` | 複製檔案描述符 | 複製一張「桌號」指向同一個餐廳 |

### 🤔 為什麼學這個？

你在終端機輸入 `ls` 時，背後發生的事是：
1. Shell 先呼叫 `fork()` 複製自己
2. 複製品用 `execvp("ls")` 把自己**變身**成 `ls` 程式
3. `ls` 跑完就結束，Shell 繼續等下一個指令

**這整個流程就是習題 6 在做的事！**

### 📂 六個小範例（從簡到難）

| 檔案 | 主題 |
|:---|:---|
| `01-fork_basic.py` | 基礎 fork 練習 |
| `02-execvp.py` | execvp 換成新程式 |
| `03-fork_exec.py` | fork + execvp 組合技 |
| `04-file_ops.py` | 開檔、讀檔、寫檔 |
| `05-dup2_redirect.py` | 用 dup2 把輸出導向檔案 |
| `06-stdio_redirect.py` | 把 `stdin`/`stdout`/`stderr` 換地方 |

## 📝 期中作業 — 記憶體安全

🔗 [期中作業完整內容](https://github.com/Luo051227/_sp/tree/master/homework/期中)

### 🎯 這個作業在做什麼？

記憶體是電腦的「倉庫」，程式執行時所有資料都放在這裡。**如果程式亂動到不該動的格子，就會出大事**。期中作業用四個 Python 程式帶你了解什麼是「記憶體安全」。

### 💡 你會學到什麼？

| 概念 | 白話解釋 |
|:---|:---|
| **堆疊 (Stack)** | 函數內的區域變數住這裡，函數結束自動清掉 |
| **堆 (Heap)** | 動態配置的資料住這裡，要自己清（不然會「漏」） |
| **緩衝區溢位 (Buffer Overflow)** | 陣列寫超過範圍，動到別人的格子（嚴重資安漏洞） |
| **記憶體泄漏 (Memory Leak)** | 忘了清掉 Heap 的資料，越用越肥 |
| **懸置指標 (Dangling Pointer)** | 拿了鑰匙但房東已經把房子賣了（指標指到被釋放的記憶體） |
| **GC（垃圾回收）** | 程式語言（像 Python）自動幫你清垃圾 |

### 🏠 生活中的比喻

> 想像記憶體是一個**超大的倉庫**，裡面有幾億個小格子，每個格子有自己的地址。
>
> - 變數 = 倉庫裡面的某一格
> - 陣列 = 連續的一排格子
> - 指標 = 寫著「地址 1234」的一張紙條
>
> **記憶體安全** = 你只能在合法的範圍內動那些格子，不能跑去開別人的抽屜。

### 📂 四個實作範例

| 檔案 | 主題 |
|:---|:---|
| `concept_demo.py` | 記憶體概念展示 |
| `compare_demo.py` | 安全 vs 不安全的對比 |
| `safe_demo.py` | 正確做法的範例 |
| `memory_game.py` | 互動式記憶體小遊戲 |

### 🚨 為什麼記憶體安全很重要？

歷史上有很多嚴重的資安事件都是因為「緩衝區溢位」造成的，例如：
- **Heartbleed 漏洞**（2014）：影響全球上百萬台伺服器
- **Morris 蠕蟲**（1988）：網際網路第一個大規模病毒

學會記憶體安全，就能避免寫出會被攻擊的程式！

## 💭 學習心得

這個學期從一個什麼都不懂的初學者，慢慢能夠：

- ✅ **看懂編譯器在做什麼**：原來寫程式不是「寫了就會跑」，中間要經過一堆翻譯
- ✅ **自己發明程式語言**：寫了 lexer、parser、interpreter
- ✅ **理解作業系統的呼叫**：`fork`、`execvp`、`dup2` 這些黑魔法變得不再神秘
- ✅ **了解多執行緒的眉角**：為什麼要 lock、為什麼會 deadlock
- ✅ **重視記憶體安全**：原來隨便寫的程式可能藏著資安漏洞

雖然一開始覺得系統程式很抽象、很底層，但透過**做中學**（每個習題都有實際可以跑的程式），慢慢就能體會其中的樂趣。
